# 🎧 Spotify Music Analytics Dashboard | Power BI

An interactive Spotify Music Analytics Dashboard developed using Microsoft Power BI to analyze song popularity, artist performance, album types, #1 hits, and music trends.

The dashboard combines data preparation, DAX-based calculations, interactive visualizations, KPI cards, filters, navigation, and analytical tables to provide an intuitive music analytics experience.

## 🎯 Project Objective

The objective of this project is to transform Spotify music data into an interactive Power BI dashboard that enables users to explore:

- Song and artist performance
- Track popularity
- #1 hits by artist
- Album-type distribution
- Explicit vs. non-explicit songs
- Music trends over time
- Artist-level performance
- Song-level performance
